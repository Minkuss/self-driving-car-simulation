# 03: Модель вождения принимает первое действие

Status: resolved
Blocked by: 02

**What to build:** Посетитель видит, как модель вождения в браузере выбирает действие для автономной машины, а журнал показывает смену решений. На простом воспроизводимом заезде модель должна хотя бы переходить от движения к замедлению и остановке у конца пути. Примеры для обучения создаёт тот же TypeScript-симулятор, Python обучает модель, а браузер исполняет экспортированный ONNX-артефакт.

- [x] Один версионированный контракт задаёт порядок и значения наблюдения и три действия модели; TypeScript и Python используют его без второй реализации дорожной логики.
- [x] Учитель создаёт воспроизводимые размеченные заезды; экспортированные примеры содержат начальное состояние, наблюдение и правильное действие, а нечисловые значения отклоняются.
- [x] Обученная в PyTorch модель экспортируется в ONNX с манифестом; на отложенных наблюдениях PyTorch и ONNX выбирают одинаковые действия.
- [x] Браузер загружает реальную модель через WebAssembly, выполняет её решения и показывает их в журнале; временное фиксированное действие больше не управляет публичным заездом.
- [x] Ошибка загрузки или несовместимая версия контракта видны посетителю; алгоритм учителя не подменяет модель в опубликованном приложении.

## Answer

Implemented and verified with the simulator, training/export and browser checks.
