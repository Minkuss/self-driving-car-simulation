# 01: Подготовка окружения и границ проекта

Status: completed
Blocked by: None (can start immediately)

**What to build:** Автор проекта может получить чистую рабочую копию, установить зависимости TypeScript-приложения и Python-обучения и запустить пустую веб-оболочку. Структура заранее показывает границы UI, симулятора, адаптера модели, общего контракта и обучения, чтобы следующий тикет добавлял поведение без реорганизации репозитория.

- [x] Выбраны и зафиксированы поддерживаемые версии Node.js и Python, один менеджер пакетов для веб-приложения и воспроизводимый способ установки Python-зависимостей; инструкции позволяют повторить установку из чистой копии.
- [x] Установлены и зафиксированы зависимости для TypeScript-сборки, выбранного UI, ONNX Runtime Web, Python/PyTorch, экспорта ONNX и необходимых проверок; Canvas использует браузерный API без отдельной библиотеки, а зависимостей без роли в MVP нет.
- [x] Пустая веб-оболочка запускается локально и собирается; доступны команды разработки, сборки и строгой проверки TypeScript. Python-окружение проходит проверку импорта библиотек обучения и экспорта.
- [x] Созданы минимальные границы UI, TypeScript-симулятора, адаптера модели, версионированного контракта и Python-обучения; направление зависимостей соответствует `AGENTS.md`, без реализации дорожного поведения.
- [x] Сгенерированные наборы примеров, временные веса, логи обучения, локальные окружения и результаты сборки исключены из репозитория; постоянные настройки и будущий финальный артефакт модели имеют понятное место.
