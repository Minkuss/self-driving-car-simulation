# 02: Первый заезд автономной машины

Status: ready-for-agent
Blocked by: 01

**What to build:** Посетитель открывает локальное веб-приложение и видит карту сверху с автономной машиной, которая плавно едет по простому пути. Это первый работающий срез TypeScript-симулятора и веб-интерфейса; временное фиксированное действие позволяет проверить движение до подключения модели в тикете 03.

- [ ] Карта, дорога и автономная машина видны в браузере; машина непрерывно движется и плавно проходит хотя бы один поворот.
- [ ] Симуляция отделена от отрисовки и может быть запущена без браузера с фиксированным начальным состоянием; одинаковый запуск даёт одинаковую поездку.
- [ ] Временное фиксированное действие явно отделено от симулятора, чтобы в тикете 03 заменить его моделью без переписывания движения.
- [ ] Приложение собирается со строгой проверкой типов; проверка поведения смотрит на движение машины, а не на внутренние функции отрисовки.
