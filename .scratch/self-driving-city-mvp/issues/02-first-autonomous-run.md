# 02: Первый заезд автономной машины

Status: completed
Blocked by: 01

**What to build:** Посетитель открывает локальное веб-приложение и видит карту сверху с автономной машиной, которая плавно едет по простому пути. Это первый работающий срез TypeScript-симулятора и веб-интерфейса; временное фиксированное действие позволяет проверить движение до подключения модели в тикете 03.

- [x] Карта, дорога и автономная машина видны в браузере; машина непрерывно движется и плавно проходит хотя бы один поворот.
- [x] Симуляция отделена от отрисовки и может быть запущена без браузера с фиксированным начальным состоянием; одинаковый запуск даёт одинаковую поездку.
- [x] Временное фиксированное действие явно отделено от симулятора, чтобы в тикете 03 заменить его моделью без переписывания движения.
- [x] Приложение собирается со строгой проверкой типов; проверка поведения смотрит на движение машины, а не на внутренние функции отрисовки.
