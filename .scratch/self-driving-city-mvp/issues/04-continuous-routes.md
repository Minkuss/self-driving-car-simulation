# 04: Непрерывные поездки по маршрутам

Status: resolved
Blocked by: 02

**What to build:** Посетитель видит, как автономная машина получает достижимую случайную цель поездки, едет по показанному на карте маршруту и после прибытия начинает следующую поездку без сброса мира.

- [x] Небольшая карта содержит несколько соединённых перекрёстков и дорожный граф; цель поездки выбирается только среди достижимых мест.
- [x] Маршрут виден контрастной линией поверх дороги и обновляется при выборе новой цели поездки.
- [x] Автономная машина плавно следует маршруту и проходит повороты без движения сквозь здания или вне дороги.
- [x] После прибытия появляется новая цель; воспроизводимый заезд завершает несколько поездок без перезагрузки и скрытой телепортации.
- [x] Проверка проходит через наблюдаемое прибытие и смену маршрута на фиксированном сценарии.

## Answer

Implemented and verified with the deterministic continuous-routes scenario.
